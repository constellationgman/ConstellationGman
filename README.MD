
# Glenn Humphrey

I build practical, local-first software focused on privacy, simplicity, and real-world usefulness.

My current project is **Constellation Transcript**, a lightweight Python tool that converts available YouTube captions into clean, verified plain-text transcripts.

## What I care about

- Local-first software
- Privacy-conscious design
- Minimal dependencies
- Simple, auditable systems
- Solving real problems without unnecessary complexity

## Current project

### Constellation Transcript

A captions-to-text utility for YouTube with Android/Termux support and Linux development underway.

The project is designed to remain lightweight, understandable, and free from telemetry, remote administration, and unnecessary background services.
